# OwnersClub WebApp

Прочитай [корневые инструкции](../AGENTS.md) и нужную строку [карты](../docs/CODE-MAP.md). [main.tsx](src/main.tsx) связывает страницы и маршруты, [api.ts](src/api.ts) и [session.ts](src/session.ts) определяют взаимодействие с API и состояние сессии.

Сверяй контракты с API и открывай ближайший тест из `tests/`. Для статической сборки проверь типы, Vite output и маршрутизацию при прямом открытии ссылки. Настройки API, CORS и публикации проверяй отдельно. [Команды и выпуск](../docs/ARCHITECTURE.md#web).
