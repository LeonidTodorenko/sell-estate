# Архив истории OwnersClub

Рабочий архив — `C:\Data\sell_estate\OwnersClub-chat-history`. Ограничь доступ текущим пользователем, SYSTEM и локальными администраторами. Для поиска и чтения используй локальные HANDOFF и README. В публичном репозитории для истории разрешён единственный путь `docs/chat-history/ownersclub.age`. Имя файла не содержит дат, названий или идентификаторов. Размер файла и время коммита видны в Git.

## Пополнение

1. Возьми новый экспорт в защищённый локальный каталог вне Git. По локальной инструкции запусти импорт с `--dry-run`, проверь отбор, затем выполни записывающий импорт и `verify`. Работа с архивом рассчитана на одного записывающего пользователя. Проверь свободный текст и служебные записи на секреты и персональные данные. Любой выявленный секрет удали из данных до подготовки снимка.
2. Используй отдельный пароль из 32 случайных байтов от криптографического генератора, записанный в Base64URL без дополнения. Храни файл вне Git с ограниченным доступом. Проверка формата отсеивает часть слабых паролей. Независимую случайную генерацию подтверждает оператор. Предусмотри защищённую резервную копию пароля.
3. Установи `pyrage==1.4.0` для Python 3.10+ из доверенного источника. Запусти `snapshot.py seal <локальный-архив> --password-file <локальный-файл> --review-approved` после ручной проверки и подтверждения происхождения пароля. Утилита использует [age v1](https://age-encryption.org/v1) со scrypt и ChaCha20-Poly1305. Файл пароля читается внутри процесса. Утилита проверяет восстановление до записи нового снимка. Если прошлый локальный снимок уже существует, сохрани его отдельно до замены. Внутренние имена, каталог и контрольные суммы зашифрованы. SQLite строится заново при проверке. Исходный ZIP и отчёт импорта первого этапа исключены из контейнера.
4. Из основного репозитория сверь статус и список уже добавленных путей. Перенеси только проверенный файл age и добавь его явным путём. Запусти `git diff --cached --name-status`, `git diff --cached --check` и `git diff --cached --numstat`. Проверь текстовые изменения на секреты и персональные данные, а бинарную запись — командой `snapshot.py verify-staged <локальный-архив> --password-file <локальный-файл> --review-approved` из основного репозитория. Она читает ciphertext из индекса Git, проверяет восстановление и сверяет снимок с рабочим архивом. Для очередного пополнения список должен содержать только `docs/chat-history/ownersclub.age`. Подготовь отдельный коммит. Перед публикацией получи подтверждение пользователя.

## Восстановление

Запусти `snapshot.py restore <существующий-защищённый-каталог> --ciphertext <снимок.age> --password-file <локальный-файл>`. Утилита проверяет аутентификацию до создания каталога и распаковывает только разрешённые обычные файлы в новую папку внутри защищённого каталога. Изучи восстановленный `tools/archive.py` перед запуском. Запусти `snapshot.py rebuild-index <каталог-восстановления>` для восстановления поиска и проверки целостности. Открой нужный диалог через локальный индекс.
